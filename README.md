# CyberSafe — Online Scam Awareness

CyberSafe is an educational website created as a TY B.Sc. Computer Science project. It helps everyday internet users recognise common online scams and learn practical ways to stay safer online.

**Live Website:** [Open CyberSafe](https://musical-malasada-ae3962.netlify.app)

## Purpose of the Project

CyberSafe was developed as part of a TY B.Sc. Computer Science field visit project. The purpose was to understand and spread awareness about common online threats, including phishing, online scams, and digital payment fraud.

The project aims to help people recognise suspicious online activities, understand basic safety practices, and learn how to respond to potential cyber fraud through educational content and an interactive quiz.

## What it covers

- **Scam awareness:** phishing, OTP fraud, UPI scams, fake job offers and online shopping fraud.
- **Scam explanations:** how common scams work and the warning signs to look for.
- **Safety guidance:** practical advice for protecting accounts, personal information and payments.
- **Interactive quiz:** scenario-based questions to check understanding.
- **India-focused help:** information about the national cybercrime helpline (1930) and the official [National Cyber Crime Reporting Portal](https://cybercrime.gov.in/).

## Run locally

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser.

You can also use the VS Code Live Server extension if you prefer a local development server.

## Learning outcomes

This project provided practical experience with structuring multi-page websites, styling responsive layouts, working with the DOM, adding interactive quiz behaviour and presenting cybersecurity awareness information in simple language.

## Project note

This is an educational awareness project. It does not detect scams automatically, investigate fraud or replace official reporting channels.
